## 🟣 板块 3｜AI 产品与技术落地（18 min｜技术主管主问）⭐核心

> **这是他最强的一块，必须问深。** 目标：区分"真做过产品"和"做过技术 demo"。

| # | 问题 | 考察点 | 红旗信号 |

| **Q10** | 47 道开发题里**还错着的 3 道**是什么？错在哪？改了**几轮**才收敛？ | 失败分析 + 迭代节奏 | "都做对了" / 答不出失败案例 |

| **Q13** | 【现场任务】给你一个真实需求：**领客是小红书留学语培机构，要做一个"选题生成 + 文案生成 + 人工审核"的助手**。**10 分钟**，给我：① 你会先问业务方哪 5 个问题 ② MVP 边界 ③ 怎么验收"文案能用"。**不用写代码，写在纸上。** | 产品 Sense + 需求澄清习惯 ⭐ | 直接开始写方案不问需求 / 没有验收标准 / 只讲 prompt 不讲流程 |

## 🔵 板块 4｜总经办真实场景压测（12 min｜HRBP 主问）⭐核心

> 总经办日常 = **日程 + 催进度 + 接待 + 调研落地 + 客户需求转技术语言**。他自评"性格谨慎"，这 4 题就是照着"谨慎"这个软肋设计的——**看反应，别听计划**。

| # | 问题 | 考察点 | 红旗信号 |
|---|---|---|---|
| **Q16** | 【场景】老板上午要一份**海外院校对比调研**，下午 3 点要；同时技术部要你确认一个需求的可行性。这两件你**都做不完**，你怎么排？给具体时间安排。 | 优先级 + 敢不敢排序 | 只说"都很重要" / 没有时间点 |
| **Q17** | 【场景】你催某部门要数据，已经催了三次没回。**第四次你怎么做**？ | 催办 + 敢不敢升级 | "再等等" / "直接发老板"（跳级） / 只会私下求情 |
| **Q18** | 【场景】老板口头提了个需求，说得很模糊（"要个能分析学生数据的工具"）。你**怎么跟他确认**？你会给他看什么让他点头？ | 需求澄清能力 | 直接猜着做 / 只会问"要什么功能" |
| **Q19** | 【场景】你同时对接**销售、运营、技术**三条线，三边都在催你。**你最怕哪种冲突**？讲一个你真处理过的例子（跨部门、跨文化都行）。 | 冲突处理 + 实战 | 只会讲"我沟通能力好" / 没真实案例 |
| **Q20**（选） | 【场景】你 12 月中要期末考试返校 **3-4 天**，手上正好压着老板的急活。你**提前怎么安排**？那几天怎么交接？ | 诚实度 + 责任边界 | 说"我可以请假/远程处理"但没具体方案 / 回避 |
